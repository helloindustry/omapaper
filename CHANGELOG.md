# Changelog

## 0.1.0

First release.

- Plain-text outliner with TaskPaper's syntax: projects, tasks, notes and `@tags`, with TaskPaper's keys using Ctrl in place of Command.
- Fold, focus (zoom), filter, saved searches, archive, move to project, duplicate, and go to project (`Ctrl+L`).
- Search with `and` / `or` / `not`, tag values, comparisons, and date words (`today`, `next Monday`, `+1 week`).
- Find and replace; Markdown shortcuts shared with Omawrite (`Ctrl+B`, `Ctrl+I`, `Ctrl+Shift+X`, `Ctrl+K`).
- Autosave with safe writes, live merge of edits made elsewhere, and a rescue copy if a file can't be written. Read-only and non-UTF-8 files are never overwritten.
- `Ctrl+N` opens a blank window; a key list on `Ctrl+/` or `F1` that you can type to filter.
- Follows the Omarchy theme and font.
